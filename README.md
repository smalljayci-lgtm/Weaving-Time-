# 织住时间 · Weaving Time

互动网页：深灰背景、全屏弹性蛛网、小蜘蛛自动修补、摄像头手势引导与吐丝结网，以及麦克风吹气生风。

## 打开网页

直接用浏览器打开本文件夹中的 index.html；也可以在 VS Code 中用 Live Server 打开 index.html。p5.js 已包含在 vendor 文件夹中，不需要安装 npm 依赖。

## 文件

- index.html：网页入口与控件。
- style.css：深灰视觉、排版和手机适配。
- web-physics.js：蛛网节点、弹性约束、断裂与路径搜索。
- sketch.js：画面绘制、蜘蛛行为和鼠标交互。
- hand-gestures.js：关键点平滑、捏合与双手拉伸。
- hand-controller.js：摄像头开关、镜像预览与识别生命周期。
- hands-worker.js：在独立线程运行手部识别，减少对蛛网动画的影响。
- breath-controller.js：本地气流声检测、环境声校准、灵敏度与麦克风生命周期。
- vendor/p5.min.js：p5.js 1.11.11。
- vendor/mediapipe/：MediaPipe 0.10.32、本地 WASM 与手部识别模型。

## 操作

- 启动页展示作品介绍，点击“开始编织”进入全屏蛛网。
- 点击左上角标题或按 Esc 返回启动页；再次进入会保留当前蛛网。
- 按住鼠标拖动蛛丝，拉远可断丝。
- W：吹一阵风。
- R：重新织网。
- 空格：暂停或继续。
- 蜘蛛会自动寻找破口，沿网移动并修补。
- 自动修补已恢复到接入摄像头前保存的实现：沿现有蛛网走到断裂连接，按原来的速度牵丝补回，保留原始丝长和原有物理参数。修补期间，手势引导、牵新丝和拉网操作等待修补完成，避免替换修补目标。

## 摄像头手势

请用 VS Code 的 Live Server 在 localhost 或 127.0.0.1 打开 index.html；直接双击文件仍可使用鼠标，但无法加载手势识别。推荐新版 Chrome 或 Edge。

进入蛛网后，点击“开启手势”并允许摄像头。识别画面只在本机处理，不上传、不录制；运行文件与模型全部随项目保存，无需再连接 CDN。

- 单手食指移动：引导蜘蛛沿现有蛛网前往目标。
- 拇指与食指捏合：抓住附近起点；保持捏合并移动，松开后将连接交给蜘蛛。新丝在蜘蛛实际爬行牵引时逐渐出现。
- 手势新丝独立显示，不加入原网的物理约束与修补目标。它不会再因额外拉力改变原网修复后的形状。原网有破口时先完成修补，再处理手势织丝。
- 双手同时捏合并向两侧拉开：拉伸蛛网，过度拉伸可以断丝。拉伸结束不会顺带生成新丝。
- 双手交叉展开不再触发风，放风交互改为下方的麦克风吹气。
- 关闭手势或返回启动页：停止摄像头与识别线程。暂停画面时，预览保留，交互暂停。

尽量让双手完整处于镜头范围内，在光线充足、背景简单的环境中体验。右上角预览显示指尖与识别状态。浏览器拒绝授权、摄像头不可用或模型加载失败时，仍可继续使用鼠标。

## 吹气生风

进入蛛网后，点击“开启吹气”并允许麦克风。这个功能独立于摄像头，不需要开启手势。继续使用 Live Server 的 localhost / 127.0.0.1 地址或 HTTPS。

1. 开启后先安静约 1.3 秒，让系统校准环境声。
2. 朝设备的麦克风轻吹约半秒。持续的气流声会产生风，声音越强，风越大；持续吹气会维持风力。
3. 面板显示实时声音强度。如果吹不动，确认声音条有反应并调高灵敏度；如果容易误触，调低灵敏度。
4. 更换设备或环境变吵时，点击“重新校准环境声”，校准期间不要吹气。
5. 点击“关闭吹气”、面板关闭按钮或返回启动页，都会释放麦克风并关闭音频上下文。暂停时不产生新的风。

当前按声音能量、频谱的噪声特征和持续时间判断气流声，不使用嘴部图像，也不能完全区分所有吹气、摩擦声、风扇声或类似的噪声。系统会过滤短促噪声和单一音调，真实麦克风下仍需按环境调整灵敏度。声音仅在浏览器内分析，不录音、不上传，也不会回放到扬声器。

“吹一阵风”按钮和 W 快捷键继续保留，未授权或没有麦克风时也能使用。
